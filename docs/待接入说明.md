# 余下三项的接入位置（不是完成状态）

## ① 桌面图标缩放（需要 `lib/ui_shell.dart`）

本补丁已包含 `lib/v39/desktop_icon_settings.dart`。原桌面页设置入口中弹出 `DesktopIconSizeDialog()`，获得比例或使用 `DesktopIconScale.load()` 读取已保存比例。此比例必须实际参与桌面图标图像宽高、GridView 的格子布局/间距及文字布局，不能只调整 `IconTheme`，因为图片和自定义桌面图标不一定使用 `Icon`。没有原 `ui_shell.dart` 时，无法准确指定应修改的节点。

## ② 字体上传超过12 MB（需要上传字体的真实页面）

`FontImportPolicy.validate(File)` 提供本机文件长度检查，临时建议 50 MB 上限、只允许 `.ttf/.otf`。原字体选择方法在拷贝前调用验证；同时将原 12MB 早退检查移除/替换。**仅添加这个文件，旧的12MB检查仍会生效。** 大字体占用存储和内存，不能无限开放。

## ⑥ 启动后关怀大弹窗（需要应用首页首次绘制位置）

`AppLaunchCarePrompt.checkAndShow(context, controller)` 已实现。应当在应用的**主页面** `initState()` 之后 `WidgetsBinding.instance.addPostFrameCallback((_) {...})` 中调用，并确保当前 widget 仍 `mounted`，并且仅首次启动/回到首页调用，不要在每一帧的 `build` 里调用。示例为：

```dart
WidgetsBinding.instance.addPostFrameCallback((_) async {
  if (!mounted) return;
  await AppLaunchCarePrompt.checkAndShow(context, widget.controller);
});
```

这只是接入代码**示例**，请根据真实的主页面类型调整 `controller` 的访问方式。此弹窗展示已获得授权的本地 `ProactiveEvent.topic`，点击打开角色私聊。它并不额外自行调用模型生成消息，不会保证原模型后台运行。

## ④ 与老日记/备忘录模块合并（需要 `models.dart` + `ui_extras.dart`）

本版已经能用角色原有 API 根据最近 20 条私聊生成可修改草稿，并保存到 `shared_preferences` 的**独立 AI 日记备忘录**。它没有修改 `LocalNote` 的旧序列化结构。若要让这些条目也显示在现有“日记”和“备忘录”应用内，需要旧 `LocalNote` 的实际字段和旧编辑页面源码，之后再改为 `controller.upsertNote` 持久化。

## 重要安全说明

本补丁不修改 `activation_service.dart`、`api_client.dart` 的现有提供商适配、`models.dart` 序列化、正式签名配置和设备 ID。新的虚拟红包只是本地“星币”账本，不涉及真实支付、转账或提现；为防止无限刷取，玩家每天每位角色最多可领3份且虚拟红包累计最多90星币。
