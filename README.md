# 心屿 OS V3.6 Android / Flutter 工程

这是 V3.5 的直接后继版本，仍使用原有包名、激活验证公钥、API 密钥存储及本地存档路径；`pubspec.yaml` 版本更新为 `3.6.0+7`。

## 核心改动

- 消息气泡：角色头像移至气泡上方；回复旁增加快捷「刷新、编辑、更多」按钮。刷新会保留旧版内容（新回复下方的历史图标查看），不再让旧回复重复进入新的 AI 上下文。
- 手机键盘：发送文字或图片时主动收起；切换模型按钮直接在聊天输入框左边。
- 图片私聊：从系统文件选图，采用 OpenAI Chat Completions、OpenAI Responses 兼容协议、Claude Messages 或 Gemini generateContent 对应的图像输入格式发送。**需要模型本身具备视觉能力，且中转站必须支持多模态；群聊图片目前仅本地展示。** 原图仅保存在应用私有目录；发送时图像内容将传给用户选定的模型服务商。单张最多 5 MB，支持 jpg/png/webp/gif。
- 聊天背景：在联系人 → 聊天背景导入本地图片，调整背景可见度 5%～100%。
- 字体：系统设置导入 TTF/OTF，重启生效，保留恢复系统字体；不传到云端。仅支持能被 Flutter 字体加载器识别的字体。
- 音乐：单曲循环、暂停、关闭播放器、从歌单中删除歌曲。应用内跨页面播放，非真正锁屏后台播放。
- 用户头像：通讯 → 我的 → 上传头像，可显示在个人聊天头像和朋友圈。
- 朋友圈：用户可自行发文字动态，AI 朋友圈权限和 AI 评论逻辑继续沿用旧版。
- Markdown：三反引号代码块以独立等宽文本块显示，非完整 Markdown 解析器，暂不支持复杂表格、LaTeX 和代码语法高亮。
- Tokens：若模型服务商响应中有 `usage`，回复下方显示输入/输出 Token；未返回不伪造数字。对官方 OpenAI 流式请求增加用量回传选项。
- 虚拟手机新增真实可用的本地相册、备忘录、日记应用，内容不上传到服务器。外部音乐/购物/钱包/支付等第三方服务**未接入**。
- 沉浸剧情继续由通讯设置中的聊天模式控制，本次未强行切换全部用户的旧模式。

## 使用 GitHub Desktop 升级

1. **先备份手机中的重要聊天和激活数据**，不要卸载旧版。
2. 解压完整工程包，直接把其中 `lib/`、`tools/`、`test/`、`pubspec.yaml` 等放入你的仓库根目录；或者使用同版本升级补丁按目录覆盖。
3. 确认 `.github/workflows/android-build.yml` 存在；继续沿用原有签名密钥 Secret `XY_RELEASE_SIGNING_BUNDLE`。
4. 在 GitHub Desktop 选择 Commit to main → Push origin。
5. 到 GitHub Actions 查看 `release-apk` 运行；**只有绿色成功并通过 flutter test 之后**，才下载构建产物。
6. 测试机覆盖安装新 APK，依次验证旧版激活状态、API、文字私聊、视觉模型、头像、字体、相册、音乐和朋友圈。随后再考虑向体验者分发。

## 安全与兼容限制

- API Key 保存在手机安全存储，不要提交到 GitHub。
- APK 签名文件和管理员私钥**没有包含在本工程中**，也不要上传到公开仓库。
- AI 图片理解必须使用提供视觉能力的模型；中转站可能拒绝图片或拒绝 `stream_options` 字段，遇到问题请检查服务商权限与协议。
- 离线一机一码激活机制延续旧版，不保证能阻止恶意逆向破解。
- 无服务器意味着关闭 App 后 AI 不会可靠地进行自主 API 请求；主动关怀沿用本地通知加前台生成机制。
- 新版没有引入需要用户额外购买的第三方服务，也没有实现真实通话、微信、网易云、知乎、购物或支付功能。
